   - Catches `CircuitBreakerError` and returns `503 { error: 'AI provider circuit is open, try again shortly' }`.
   - Catches uncaught provider / network errors and returns `502 { error: <message> }`.
   - Responds `200` with the `AIResponse<string>` payload.

## Exact Types & Fields Relied On

### 1. `ai-provider` Module (`products/multi-tenant-ai/modules/ai-provider/`)
- `AIResponse<T>` (`core/types.ts`):
  - `success: boolean` — boolean flag indicating successful generation.
  - `text?: string` — output text generated by the model.
  - `provider: string` — string identifier of the provider (`'openai' | 'anthropic' | 'gemini'`).
  - `model?: string` — model ID used for generation.
  - `usage?: { inputTokens?: number; outputTokens?: number }` — token consumption metrics.
  - `error?: { code: AIErrorCode; message: string }` — structured error details if `success` is `false`.
- `OpenAIConfig` / `AnthropicConfig` / `GeminiConfig`:
  - `{ apiKey: string; baseUrl?: string; defaultModel?: string }` — configuration object passed to provider constructors.
- Provider Classes (`OpenAIProvider`, `AnthropicProvider`, `GeminiProvider`):
  - `constructor(config: { apiKey: string })`
  - `generateText(request: AIRequest): Promise<AIResponse<string>>`

### 2. `enterprise-features` Module (`products/multi-tenant-ai/modules/enterprise-features/`)
- `CircuitBreaker` (`core/circuit-breaker.ts`):
  - `constructor(config: { failureThreshold: number; resetTimeoutMs: number })`
  - `execute<T>(fn: () => Promise<T>): Promise<T>` — wraps execution, tracks consecutive failures, transitions states (`CLOSED` -> `OPEN` -> `HALF_OPEN`), and throws `CircuitBreakerError` when open.
- `CircuitBreakerError` (`core/circuit-breaker.ts`):
  - `code: CircuitBreakerErrorCode` (`'CIRCUIT_OPEN' | 'HALF_OPEN_PROBE_IN_PROGRESS' | 'INVALID_CONFIG'`)
  - `message: string`
  - `name: 'CircuitBreakerError'`
- `MemoryTracer` & `Span` (`core/tracer.ts`, `core/types.ts`):
  - `tracer.startSpan(name: string): Span` — begins a new tracing span named `'ai.generateText'`.
  - `span.setAttribute(key: string, value: SpanAttributeValue): void` — attaches key-value metadata (`'provider' -> 'openai' | 'anthropic' | 'gemini'`).
  - `span.end(): void` — records completion timestamp and span duration.

## Configuration Shape & Provider Comparison

- **Constructor Compatibility**: Inspection of all three adapter implementations (`openai-adapter.ts`, `anthropic-adapter.ts`, `gemini-adapter.ts`) confirms that they all accept identical configuration shapes (`{ apiKey: string; baseUrl?: string; defaultModel?: string }`).
- **Validation**: All three adapters throw an explicit `Error('CONFIG_MISSING: ... apiKey is required')` if the `apiKey` property is falsy.
- **Provider Resolution**: `getConfiguredProvider()` checks environment variables in the required order (`OPENAI_API_KEY` -> `ANTHROPIC_API_KEY` -> `GEMINI_API_KEY`) and cleanly passes `{ apiKey: <key> }` without requiring SDK installations.
